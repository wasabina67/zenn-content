- 開発現場において「ソースコードの履歴を管理する」という行為は、今や空気のように当たり前の存在です。
- しかし、現代の標準である Git に至るまでには、先人たちが直面した不便さを解消するための技術革新の積み重ねがありました。
- 本記事では、バージョン管理システム（VCS）の代表的な3つのツールを軸に、その進化の歴史を振り返ります。

## 1. CVS (Concurrent Versions System)
**〜共同開発の幕開け〜**

1990年頃に登場した CVS は、それまで個人のローカル環境で「ファイル名に日付をつけて保存する」といった原始的な管理をしていた開発現場に革命をもたらしました。

## 2. Subversion (SVN)
**〜信頼性と安定性の向上〜**

2000年頃、CVS の決定的な弱点を克服するために登場したのが Subversion（SVN）です。「CVS よりも優れた CVS」を目指して設計されました。

## 3. Git
**〜分散型による自由と高速化〜**

2005年、Linuxカーネルの開発者であるリーナス・トーバルズ氏によって開発された Git は、それまでの「中央集権型」の常識を覆しました。
